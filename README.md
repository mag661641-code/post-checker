# Проверка постов в реестре

Веб-сервис на **Streamlit** для проверки постов компании (металлопрокат) по
файлу «РРП. Реестр постов/отгрузок.xlsx». Находит ошибки в реестре и текстах
постов, объясняет простыми словами **где** ошибка (лист, строка Excel, колонка),
**что** не так, **почему** это важно и **как** исправить.

Сервис **никогда не изменяет** ваш файл — он только читает его и формирует
отдельный отчёт. Если какая-то проверка не сработала, сервис не «падает»
целиком, а показывает это отдельной строкой и продолжает остальные проверки.

---

## Что проверяет сервис

- **Реестр постов:** пустые поля, нераспознанные даты, несоответствие статуса и
  даты, дубли ссылок, ссылки не того бренда, ссылки в закрытый чат у
  «Выложено», неполный набор площадок, неизвестные домены, написание типа поста.
- **Тексты постов:** контактный блок бренда, контакты/название чужого бренда,
  обязательные хэштеги, незаполненные заглушки `[…]`, остатки промтов, звёздочки
  разметки, типографика (тире, двоеточия в списках, двойные пробелы, кавычки),
  опечатки-повторы, жёсткие переносы строк, длина текста для Telegram, фото.
- **Праздники:** запланирован ли пост к каждому обязательному празднику.
- **Онлайн (по кнопке):** доступность и совпадение опубликованных постов
  (Telegram, ВКонтакте — при наличии ключа, Одноклассники/Max/Дзен — доступность).
- **Орфография (по кнопке, нужен интернет):** через Яндекс.Спеллер с белым
  списком терминов.

Уровни замечаний: 🔴 **Ошибка** (публиковать нельзя), 🟡 **Предупреждение**
(проверить глазами), 🔵 **Совет** (мелочь).

## Установка (для тех, кто не программист)

### Шаг 1. Установить Python

**Windows:**
1. Откройте <https://www.python.org/downloads/> и скачайте Python 3.11 или новее.
2. Запустите установщик. **ОБЯЗАТЕЛЬНО** поставьте галочку внизу окна
   **«Add Python to PATH»**, затем нажмите «Install Now».

**macOS:**
1. Откройте <https://www.python.org/downloads/macos/> и установите Python 3.11+.
2. Либо через Homebrew: `brew install python`.

Проверка (в терминале): `python --version` — должно показать `Python 3.11` и выше.

### Шаг 2. Открыть терминал в папке проекта

**Windows:** откройте папку `post_checker` в Проводнике, в адресной строке
напечатайте `cmd` и нажмите Enter.

**macOS:** откройте «Терминал», напечатайте `cd ` (с пробелом) и перетащите
папку `post_checker` в окно терминала, затем Enter.

### Шаг 3. Создать окружение и установить зависимости

**Windows:**
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS:**
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Шаг 4. Запустить сервис

```
streamlit run app.py
```

Откроется браузер с адресом `http://localhost:8501`. Если не открылся —
скопируйте этот адрес в браузер вручную.

Как пользоваться:
1. На странице **Загрузка** выберите файл `.xlsx`.
2. Смотрите результаты на страницах **Сводка**, **Реестр**, **Тексты постов**,
   **Праздники** (меню слева).
3. При необходимости запустите **Онлайн-проверку** и скачайте отчёт на странице
   **Экспорт**.

Чтобы остановить сервис — вернитесь в терминал и нажмите `Ctrl+C`.

## Пароль для входа (закрыть доступ)

Чтобы сервис спрашивал пароль при входе (удобно, если приложение развёрнуто в
интернете как публичное на Streamlit Cloud):

**Локально:** скопируйте `.streamlit/secrets.toml.example` в
`.streamlit/secrets.toml` и впишите:
```toml
[auth]
password = "ваш_пароль"
```

**На Streamlit Community Cloud:** откройте приложение → **Settings → Advanced
settings → Secrets** и вставьте туда те же две строки. Так можно держать
приложение публичным (их число не ограничено), но закрытым паролем — без него
внутрь никто не попадёт. Пароль хранится в секретах, в коде и в GitHub его нет.

Если блок `[auth]` не задан — вход свободный (удобно при локальной работе).
Кнопка **«Выйти»** появляется в боковой панели после входа.

## Чтение реестра из Google-таблицы (необязательно)

Если реестр ведётся в Google-таблице, сервис может читать её напрямую — без
ручной выгрузки `.xlsx`. Настраивается через сервисный аккаунт Google
(доступ только на **Чтение** — сервис ничего не меняет в таблице).

1. **Создайте сервисный аккаунт.** Зайдите в [Google Cloud Console](https://console.cloud.google.com/)
   → создайте проект → **APIs & Services → Enable APIs** → включите
   **Google Drive API** → **Credentials → Create credentials → Service account**.
2. **Скачайте ключ.** У созданного аккаунта: **Keys → Add key → JSON**. Сохранится
   файл-ключ. В нём есть строка `client_email` — это адрес вида
   `имя@проект.iam.gserviceaccount.com`.
3. **Дайте доступ к таблице.** Откройте Google-таблицу → **Настройки доступа** →
   добавьте этот `client_email` как **Читателя**.
4. **Вставьте ключ в секреты.** Проще всего вставить **весь скачанный JSON-файл
   целиком** между тройными кавычками — ничего переделывать не нужно:
   ```toml
   gcp_service_account_json = '''
   { ...сюда содержимое скачанного файла-ключа целиком... }
   '''
   ```
   Локально это файл `.streamlit/secrets.toml`, в облаке — **Settings → Advanced
   settings → Secrets**. Образец и альтернативный формат — в
   `.streamlit/secrets.toml.example`.
5. **Пользуйтесь.** На странице **Загрузка** откройте вкладку
   **«Из Google-таблицы»**, вставьте ссылку на таблицу и нажмите
   «Загрузить из Google».

Ручная загрузка файла `.xlsx` при этом остаётся как запасной способ.

## Ключ ВКонтакте (необязательно)

Нужен только для сверки текста постов ВКонтакте через официальный API. Без него
сервис просто проверяет, что страница ВКонтакте открывается.

1. Скопируйте файл `.streamlit/secrets.toml.example` в `.streamlit/secrets.toml`.
2. Впишите сервисный ключ доступа сообщества:
   ```toml
   [vk]
   service_key = "ваш_ключ"
   ```
Файл `secrets.toml` не попадает в git (защищён `.gitignore`).

## Как поменять справочник брендов

Если изменился телефон, сайт или хэштеги — откройте страницу **Настройки**:
- вкладка **Бренды** — контакты и полный JSON (хэштеги, id групп, каналы);
- вкладка **Правила и пороги** — включение/выключение проверок, лимиты,
  ожидаемые площадки, словари нормализации;
- вкладка **Белый список слов** — термины и марки стали для орфографии.

Нажмите **«Сохранить»** и запустите проверку заново (перезагрузите файл на
странице «Загрузка»). Кнопка **«Сбросить к стандартным»** возвращает исходные
значения. Файлы настроек лежат в папке `config/` (`brands.json`, `rules.json`,
`whitelist.txt`) и их можно редактировать и вручную.

## Частые проблемы

**Порт занят / «Port 8501 is already in use».**
Запустите на другом порту: `streamlit run app.py --server.port 8502`.

**Ошибка установки пакета.**
Обновите pip: `python -m pip install --upgrade pip`, затем повторите
`pip install -r requirements.txt`. Убедитесь, что окружение активировано
(в начале строки терминала должно быть `(.venv)`).

**Файл не читается / не тот лист.**
Сервис ждёт листы «Реестр постов», «СМУ», «ИМП», «МПЭ», «МПИ», «АПС»,
«Обязательные праздники». Если листа нет — на странице «Загрузка» будет
понятное сообщение. Проверьте, что это `.xlsx` (не `.xls` и не Google Sheets).

**«ModuleNotFoundError: rapidfuzz».**
Не установлены зависимости. Выполните `pip install -r requirements.txt`.
Без `rapidfuzz` онлайн-сверка текста не сравнивает тексты (только доступность).

**Онлайн-проверка ничего не находит или пишет «проверьте вручную».**
Площадки (Одноклассники, Max, Дзен, иногда ВКонтакте) могут блокировать
автоматические запросы. Это не ошибка сервиса — проверьте такие посты вручную.

## Ограничения

Сервис проверяет **автоматически**: структуру реестра, даты, ссылки и дубли,
контактные блоки, хэштеги, остатки шаблонов и промтов, типографику, длину
текста, наличие фото-ссылок, сверку с праздниками, орфографию (по кнопке).

Всё равно нужно смотреть **глазами**:
- качество и содержание фотографий (сервис проверяет только наличие ссылки);
- смысл и достоверность текста, фактические данные о металле (марки, размеры,
  цены);
- тон и уместность поздравлений;
- итоговый вид поста в конкретной соцсети.

⚠️ **Важно:** автоматическая проверка соцсетей зависит от самих площадок и может
перестать работать, если они изменят свои сайты или правила доступа.

## Для разработчика

Структура:
```
post_checker/
├── app.py                  # точка входа Streamlit (страница «Загрузка»)
├── ui_common.py            # связка интерфейса и модуля checker, кеширование
├── pages/                  # страницы Streamlit
├── checker/                # логика проверок (работает без Streamlit)
│   ├── loader.py           # чтение Excel, объединённые ячейки, группировка
│   ├── normalize.py        # даты, ссылки, телефоны, соцсети, типы
│   ├── registry_checks.py  # проверки реестра
│   ├── text_checks.py      # проверки текстов
│   ├── holidays.py         # расчёт дат праздников
│   ├── online_checks.py    # запросы к площадкам
│   ├── speller.py          # орфография (Яндекс.Спеллер)
│   ├── report.py           # экспорт в xlsx/csv
│   ├── config.py           # загрузка/сохранение конфигурации
│   └── models.py           # Issue, PostRecord, RegistryRow, Level
├── config/                 # brands.json, rules.json, whitelist.txt
└── tests/                  # pytest
```

Запуск тестов:
```
pytest -q
```

Модуль `checker` не зависит от Streamlit — его можно использовать в скриптах и
тестах отдельно от интерфейса.
